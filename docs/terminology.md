# Terminology

| Use this | Do not use this |
|---|---|
| CA Recovery, incomplete CA, E(CA) | CA1, CA2, “makeup exam module” as the whole product |
| Subject offering | “the subject” when you mean a teaching instance |
| Registration number + subject code | Student name, or subject title, as the result key |
| Department Administrator | SUPER_ADMIN, HOD user role |
| Physical verification | Digital HOD approval |
| Official resource | Study Room shared file |
| Notification (delivery record) | Notice (announcement content) |
| Calendar representation | Treating calendar as the CA schedule source of truth |
| SENT / provider accepted | Delivered to the student |
| Modular monolith | Microservices |

Timezone in config defaults to `Asia/Colombo`. Host-local TZ must not be assumed for CA windows.
