# Handoff

A new developer can take over when they can do all of the following without guessing academic policy.

- [ ] Run API, worker, and web from [development/local-setup.md](./development/local-setup.md)
- [ ] Name the three roles and why HOD is not a login
- [ ] Point to result identity and Study Room student-only tests
- [ ] Explain dashboard vs results vs GPA ownership
- [ ] Explain CA: physical verify, complete ≠ grade
- [ ] Start the worker and know Redis is required for API↔worker jobs
- [ ] Find `/api` prefixes in [api/README.md](./api/README.md)
- [ ] Find env names in [development/env-reference.md](./development/env-reference.md) without copying secrets
- [ ] Read [limitations.md](./limitations.md) and [architecture/integration-debt.md](./architecture/integration-debt.md)
- [ ] Run `npm test` and `npm run check:docs`

Knowledge transfer: walk [qa/demonstration-scenario.md](./qa/demonstration-scenario.md) on a staging instance when one exists. Do not use production student data.
